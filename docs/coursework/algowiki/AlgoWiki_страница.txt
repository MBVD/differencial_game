== Свойства и структура алгоритма ==

=== Общее описание алгоритма ===

Алгоритм предназначен для приближённого вычисления ''функции цены'' V(x,&nbsp;y) дифференциальной игры преследования «шофёр–убийца» в редуцированном пространстве<ref name="isaacs">Айзекс Р. Дифференциальные игры. — М.: Мир, 1967. — 480 с.</ref>. Платой в игре является время до захвата. Поэтому V(x,&nbsp;y) — это время, за которое преследователь P (шофёр) гарантированно захватывает убегающего E из относительного положения (x,&nbsp;y), если оба игрока действуют оптимально.

Функция цены является вязкостным решением стационарного уравнения Гамильтона–Якоби–Айзекса (основного уравнения Айзекса). Методом характеристик это уравнение решается лишь по частям, между сингулярными поверхностями. Численный алгоритм позволяет получить V сразу во всей расчётной области, включая сингулярные поверхности и барьер. Обзор аналитических и численных исследований этой игры см. в обзоре<ref name="pt" />.

Алгоритм относится к классу ''полулагранжевых схем'' (semi-Lagrangian schemes) для уравнений Гамильтона–Якоби–Беллмана–Айзекса. Описываемый вариант — ''полностью дискретная схема'' Барди–Фальконе–Соравиа<ref name="bfs">Bardi M., Falcone M., Soravia P. Fully discrete schemes for the value function of pursuit-evasion games // Advances in Dynamic Games and Applications. Annals of the International Society of Dynamic Games, vol. 1. — Boston: Birkhäuser, 1994.</ref><ref name="ff">Falcone M., Ferretti R. Semi-Lagrangian Approximation Schemes for Linear and Hamilton–Jacobi Equations. — Philadelphia: SIAM, 2014.</ref>. В ней дискретизируются и время (шаг τ), и пространство (равномерная сетка с шагом h). Значения функции цены между узлами восстанавливаются билинейной интерполяцией. Полученное сеточное уравнение имеет вид неподвижной точки нелинейного оператора. Оно решается ''методом итераций по значению'' (value iteration) в варианте Якоби: на каждой итерации новое приближение во всех узлах вычисляется только по предыдущему приближению.

Основные особенности алгоритма:
* схема опирается на дискретный принцип динамического программирования: цена в узле равна минимаксу по управлениям от суммы «время шага + цена в точке, куда приводит шаг»;
* множества управлений заменяются конечными наборами: φ ∈ {−1, 0, 1} для шофёра и |Ψ| равномерно распределённых направлений ψ для убегающего;
* захват засчитывается, если отрезок шага пересекает круг захвата, а не только если конец шага попал внутрь круга;
* в области, из которой убегающий уходит от захвата, точная цена бесконечна; в реализации она заменяется ограничением T<sub>max</sub> («потолком»).

=== Математическое описание алгоритма ===

'''Непрерывная задача.''' Редуцированная динамика игры (система координат связана с шофёром):

: ẋ = f<sub>1</sub>(x, y, φ, ψ) = −(w<sub>1</sub>/R)·y·φ + w<sub>2</sub>·sin ψ,
: ẏ = f<sub>2</sub>(x, y, φ, ψ) = (w<sub>1</sub>/R)·x·φ − w<sub>1</sub> + w<sub>2</sub>·cos ψ,

где
* w<sub>1</sub> — скорость шофёра;
* w<sub>2</sub> < w<sub>1</sub> — скорость убегающего;
* R — минимальный радиус поворота автомобиля;
* φ ∈ [−1, 1] — управление шофёра (кривизна траектории);
* ψ ∈ [0, 2π) — управление убегающего (направление движения).

Обозначим f = (f<sub>1</sub>, f<sub>2</sub>), z = (x, y).

Терминальное множество (круг захвата радиуса l): 𝒯 = { z : x<sup>2</sup> + y<sup>2</sup> ≤ l<sup>2</sup> }. Функция цены удовлетворяет основному уравнению Айзекса (порядок min и max в нём можно менять: динамика разделяется на слагаемое, зависящее только от φ, и слагаемое, зависящее только от ψ, поэтому выполнено условие Айзекса и игра имеет цену):

: min<sub>φ∈[−1,1]</sub> max<sub>ψ∈[0,2π)</sub> [ V<sub>x</sub>·f<sub>1</sub>(z, φ, ψ) + V<sub>y</sub>·f<sub>2</sub>(z, φ, ψ) + 1 ] = 0,   z ∉ 𝒯;
: V(z) = 0,   z ∈ 𝒯.

'''Дискретизация.''' Расчётная область Ω = [−L, L]<sup>2</sup> покрывается равномерной сеткой

: z<sub>ij</sub> = (x<sub>i</sub>, y<sub>j</sub>),   x<sub>i</sub> = −L + i·h,   y<sub>j</sub> = −L + j·h,   i, j = 0, …, n−1,

где n = 2L/h + 1 — число узлов по каждой координате. Множества управлений заменяются конечными:

: Φ = {−1, 0, 1},   Ψ = { ψ<sub>k</sub> = 2πk/m : k = 0, …, m−1 }.

Шаг по времени согласуется с шагом сетки: τ = h / (w<sub>1</sub> + w<sub>2</sub>), т.&nbsp;е. вблизи круга захвата точка смещается за шаг примерно на одну ячейку. Для полулагранжевой схемы с линейной интерполяцией локальная погрешность в областях гладкости имеет порядок O(τ + h<sup>2</sup>/τ)<ref name="ff" />, поэтому при τ ~ h получается O(h).

Для узла z и пары управлений (φ, ψ) точка, в которую система переходит за время τ (явный шаг Эйлера вдоль характеристики), равна

: z<sup>+</sup>(z, φ, ψ) = z + τ·f(z, φ, ψ).

Пусть отрезок [z, z<sup>+</sup>] пересекает 𝒯. Тогда θ(z, φ, ψ) ∈ [0, 1] — наименьший параметр, при котором точка z + θ·(z<sup>+</sup> − z) попадает на окружность захвата. Это наименьший корень квадратного уравнения |z + θ·(z<sup>+</sup> − z)|<sup>2</sup> = l<sup>2</sup> на отрезке [0, 1].

'''Ограничение T<sub>max</sub>.''' Если убегающий может уклоняться от захвата сколь угодно долго, точная цена бесконечна. Захват гарантирован из любого положения, только если l/R > √(1 − γ<sup>2</sup>) + arcsin γ − 1, где γ = w<sub>2</sub>/w<sub>1</sub><ref name="isaacs" />. В остальных случаях существует барьер, через который цена терпит разрыв, и часть плоскости соответствует бесконечной цене. Поэтому значения ограничиваются сверху величиной T<sub>max</sub>: значение V = T<sub>max</sub> означает, что за время T<sub>max</sub> захват не гарантирован.

Обозначим через I[V](z) билинейную интерполяцию сеточной функции V = {V<sub>ij</sub>} в точке z, доопределённую так: I[V](z) = 0 при z ∈ 𝒯 и I[V](z) = T<sub>max</sub> при z ∉ Ω.

'''Сеточное уравнение.''' Введём стоимость перехода:

: Q[V](z, φ, ψ) = τ·θ(z, φ, ψ), если отрезок [z, z<sup>+</sup>] пересекает 𝒯;
: Q[V](z, φ, ψ) = τ + I[V](z<sup>+</sup>(z, φ, ψ)) иначе.

Определим оператор S:

: (SV)<sub>ij</sub> = 0, если z<sub>ij</sub> ∈ 𝒯;
: (SV)<sub>ij</sub> = min{ T<sub>max</sub>, min<sub>φ∈Φ</sub> max<sub>ψ∈Ψ</sub> Q[V](z<sub>ij</sub>, φ, ψ) }, если z<sub>ij</sub> ∉ 𝒯.

Приближённая функция цены — неподвижная точка оператора: V = SV.

'''Итерации по значению.''' Начальное приближение: V<sup>(0)</sup><sub>ij</sub> = 0 при z<sub>ij</sub> ∈ 𝒯 и V<sup>(0)</sup><sub>ij</sub> = T<sub>max</sub> иначе. Итерации

: V<sup>(k)</sup> = S V<sup>(k−1)</sup>,   k = 1, 2, …

продолжаются, пока невязка r<sub>k</sub> = max<sub>ij</sub> |V<sup>(k)</sup><sub>ij</sub> − V<sup>(k−1)</sup><sub>ij</sub>| не станет меньше заданной точности ε или пока не будет достигнуто максимальное число итераций K<sub>max</sub>.

'''Синтез управлений.''' По найденной сеточной функции цены управления в точке z выбираются из того же дискретного минимакса:

: ψ*(φ) = arg max<sub>ψ</sub> Q[V](z, φ, ψ),   φ* = arg min<sub>φ∈Φ</sub> Q[V](z, φ, ψ*(φ)),   ψ* = ψ*(φ*).

В областях гладкости V это согласуется с формулами sin ψ* = V<sub>x</sub>/√(V<sub>x</sub><sup>2</sup> + V<sub>y</sub><sup>2</sup>), cos ψ* = V<sub>y</sub>/√(V<sub>x</sub><sup>2</sup> + V<sub>y</sub><sup>2</sup>), φ* = −sgn(x·V<sub>y</sub> − y·V<sub>x</sub>), но, в отличие от них, применимо и на барьере и рассеивающих линиях, где градиент V не определён. Синтез управлений не входит в итерационный процесс и выполняется отдельно для каждого запроса.
